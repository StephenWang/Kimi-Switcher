# 写了个 Kimi 换号工具，几个账号放在一起管

用 Kimi Code CLI，手里有两个以上账号的时候，换号就成了一件有点烦的小事。

登录信息要重新处理，换完还得确认一下是不是目标账号。想查额度，又得再操作一遍。几次下来，代码没写多少，账号倒是认得很熟。

所以我做了个 Windows 小工具：**Kimi Switch**。几个账号放在同一个窗口里，哪个正在用、额度用了多少，打开就能看到。

第一个版本 v0.1.0 已经发布，源码也放到了 GitHub。

## 先把账号加进来

电脑上需要先装好 Kimi Code CLI。**不支持 CLI 0.1.1**，因为它缺少助手需要的 `login --region` 命令。

如果你已经在本机 CLI 登录过，打开助手，点“导入当前账号”，填个名字就能保存。

添加另一个账号，就点“＋ 添加账号”，填写名称、选择地区，跟着官方浏览器授权页面完成登录，再回到助手等待保存。

添加和导入不会自动换掉当前账号，可以先整理好，再选用哪个。

账号名建议稍微认真一点。三个账号都叫“备用”，下次打开还是要猜，只是从终端猜换成了看界面猜。

## 换号记住一个顺序

**关闭 Kimi CLI → 点击目标账号的“切换” → 重新启动 `kimi`。**

已经运行的 CLI 会话需要关闭后再打开，不会在后台自动换号。

当前账号的卡片有蓝色边框和淡蓝背景，右下角标着绿色“当前”。换完之后看一眼，确认好了再继续干活。

## 额度也放在了卡片上

每个账号会显示套餐、7 天和 5 小时的额度使用情况，以及重置时间。

注意，进度条显示的是**已使用比例**。30% 是用了 30%，不是只剩 30%，别急着换号。

卡片上的刷新箭头用来更新单个账号，顶部的刷新按钮更新全部账号。查询失败会提示错误，并保留上次的数据供参考。

旁边的文档编辑图标用于改名字，垃圾桶用于移除助手保存的账号副本。删除前会确认，也不会替你删除 Kimi 账户或注销 CLI 当前登录。

界面做了深浅两套主题，点太阳或月亮切换。窗口可以拖拽、最小化和最大化，日常放在旁边，需要换号时打开就行。

## 登录信息怎么保存

助手保存的凭据使用 Windows DPAPI 本地加密，绑定当前 Windows 用户和电脑。

暂时不支持把账号数据复制到另一台电脑继续用。换电脑后，需要重新完成官方授权。

## 下载和源码

目前提供 Windows 10/11 x64 版本，需要 WebView2 Runtime。

打开 Release 页面，在 Assets 中选择带 `setup.exe` 的安装包，或选择独立应用 EXE。普通使用不用下载 Source code，那个是准备研究代码时再下的。
