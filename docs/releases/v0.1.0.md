## Kimi Switch v0.1.0

Kimi Code CLI 多账号登录切换助手，基于 Rust + Tauri 2 开发，支持 Windows 10/11 x64。

### 功能

- 通过官方 CLI 授权添加账号，或导入本机已登录账号；支持重命名与删除助手保存的账号副本。
- 切换 CLI 登录凭据，提供加密备份、失败回滚和启动恢复。
- 查看套餐、7 天与 5 小时额度已用比例及重置时间，支持单账号和全部刷新。
- 使用 Windows DPAPI 本地加密保存凭据，支持中国大陆及全球地区账号。
- 深浅主题、当前账号高亮及绿色 Badge、SVG 操作图标。
- 无边框窗口，支持拖拽、最小化、最大化／还原及关闭。

### CLI 兼容性

**不支持 Kimi Code CLI 0.1.1**：该版本缺少助手所需的 `login --region` 命令。

### 使用说明

- 需要 Microsoft Edge WebView2 Runtime。
- 切换前关闭 Kimi CLI 及相关会话，切换后重新启动 `kimi`。
- 删除仅移除助手保存的副本，不会注销 CLI 当前登录。
- DPAPI 数据绑定当前 Windows 用户和电脑，暂不支持跨电脑凭据导出／导入。
